# goit-markup-hw-01
web studio project
This project was developed to practice the fundamentals of HTML markup and to gain a clear understanding of static web page structure. In accordance with HTML5 standards:
- Semantic HTML elements (such as `<header>`, `<nav>`, `<main>`, and `<footer>`) are used to improve content structure and readability.
- The page layout is designed with attention to content hierarchy and basic accessibility principles.
- Styling and interactivity (CSS and JavaScript) are intentionally excluded, as the primary focus of this assignment is markup structure.
- All media assets are organized in a dedicated `images` directory to maintain a clear and maintainable file structure.
This project was created as part of the GoIT Fullstack Developer course and represents an introductory assignment in the HTML Markup module.
